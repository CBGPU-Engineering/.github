# CBGPU Engineering

**Student-built infrastructure for research and school life.**

[Visit CBGPU](https://cbgpu.com) · [Explore the platform](https://github.com/CBGPU-Engineering/CBGPU-web) · [Contact](mailto:info@cbgpu.com)

We build and maintain **CBGPU**, a platform developed at Chungbuk Science High School. Starting with shared GPU access, CBGPU brings computing resources, student services, and development tools into one connected workspace.

## What we build

| Area | Focus |
| :--- | :--- |
| Research computing | GPU scheduling, remote access, and job coordination |
| Student services | School applications, shared materials, notifications, and everyday tools |
| Developer infrastructure | Project deployment, service gateways, and operational tooling |
| Mobile experience | A Flutter Android app with notifications and home-screen widgets |

## How we work

We use **Jira** for team planning, **GitHub** for code and review, and **Slack** for engineering discussions. Pull requests should explain the problem, the resulting behavior, and how the change was validated. Link the relevant Jira work item when one exists.

For public bug reports and feature suggestions, use the repository issue forms. For security concerns, follow the [security policy](https://github.com/CBGPU-Engineering/CBGPU-web/blob/main/SECURITY.md) and report privately.
